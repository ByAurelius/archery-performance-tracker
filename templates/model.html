How it works

The AI looks at an athlete's last 60 sessions (scores, grouping, tiredness, focus and wind) and predicts the next 30. It learnt how scores usually develop from the sessions of all athletes, and it updates an athlete's prediction automatically every time a new session is saved. It was last trained on {{ evaluation.trained_at }}.

🔬 Technical details (model evaluation used in the research)
Model

Shared 2-layer LSTM ({{ c.hidden }} units, dropout {{ c.dropout }}) with a linear head. Input: {{ c.input_days }} sessions × {{ c.features | length }} features ({{ c.features | join(', ') }}), standardised per archer. Output: the next {{ c.horizon }} session averages relative to the mean of the last {{ c.anchor_days }} sessions. Chronological split on target days (train < {{ c.train_end }} ≤ validation < {{ c.val_end }} ≤ test). {{ c.train_windows }} training and {{ c.val_windows }} validation windows, early stopping (best epoch {{ c.best_epoch }}, validation MAE {{ c.val_mae }}). Prediction interval: Monte Carlo dropout ({{ c.mc_samples }} samples) combined with the archer's day-to-day SD, ±1.28 σ for 80 %. Trained {{ evaluation.trained_at }} in {{ evaluation.duration_s }} s.
